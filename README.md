# Greekon – Modern Digital Experience Platform

**Greekon** is a premium, high-performance web application built with the latest technologies to deliver a stunning digital experience. It features immersive 3D interactions, smooth animations, and a sleek modern aesthetic.

---

## 🚀 Teck Stack

Greekon is built on a cutting-edge foundation to ensure performance, scalability, and visual excellence:

- **Framework**: [Next.js 15 (App Router)](https://nextjs.org/)
- **Core**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) & [Vanilla CSS](https://developer.mozilla.org/en-US/docs/Web/CSS)
- **Animations**:
    - [Framer Motion](https://www.framer.com/motion/) (Micro-interactions & transitions)
    - [GSAP](https://gsap.com/) (Complex scroll-driven and timeline animations)
- **3D Graphics**: [Three.js](https://threejs.org/) with [@react-three/fiber](https://github.com/pmndrs/react-three-fiber) & [@react-three/drei](https://github.com/pmndrs/drei)
- **UI Components**: [Radix UI](https://www.radix-ui.com/) & [Shadcn UI](https://ui.shadcn.com/)
- **Form Handling**: [React Hook Form](https://react-hook-form.com/) & [Zod](https://zod.dev/)

---

## ✨ Key Features

- **Immersive 3D Atmosphere**: Interactive 3D gallery and scenes powered by Three.js.
- **Scroll-Driven Storytelling**: Advanced animations synchronized with user scrolling.
- **Premium Design System**: Dark-themed, glassmorphic UI with custom typography.
- **Responsive & Optimized**: Fully responsive across all devices with Next.js image optimization.
- **Dynamic Content**: Sections for Services, Portfolio, Blog, and real-time Feedback.

## 📁 Project Structure

```text
greekon/
├── public/              # Static assets (images, icons, etc.)
└── src/
    ├── app/             # Next.js App Router (Pages & API)
    │   ├── about-us/    # About Us page
    │   ├── blog/        # Blog & Articles
    │   ├── services/    # Services & Pricing
    │   └── our-work/    # Portfolio/Projects
    ├── components/
    │   ├── scenes/      # Page-specific sections (Home, About, etc.)
    │   ├── layouts/     # Shared layouts (Navbar, Footer)
    │   ├── shared/      # Reusable business components
    │   └── ui/          # Low-level UI primitives (buttons, inputs)
    ├── lib/             # Utility functions and shared logic
    └── styles/          # Global styles and Tailwind configuration
```

## 🛠️ Getting Started

### Prerequisites
- Node.js 18+ 
- npm / pnpm / yarn

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/greekon.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.
